# Adwerk

Interne ad- en bannereditor van daar-om.nl: social ads, geanimeerde HTML5 bannersets, GIF en video, met live samenwerken.

- Hosting: GitHub Pages (deze repository bevat de gebouwde bestanden)
- Inloggen en data: Supabase (project Adwerk), Google-login alleen voor @daar-om.nl
- Broncode: `adwerk-source.zip` (React, Vite, Tailwind, Radix/shadcn-stijl, Konva, gifenc, JSZip)

Ontwikkelen: pak de zip uit, `npm install`, `npm run dev`. Bouwen: `npm run build` en upload de inhoud van `dist/`.
